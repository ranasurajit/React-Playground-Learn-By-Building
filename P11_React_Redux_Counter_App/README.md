# 🚀 Redux Counter App

## 📌 Overview

A simple and clean **Redux Counter Application** built using React.\
This project demonstrates core Redux concepts like **store, reducer,
dispatch, and selector** along with modern UI using Tailwind CSS.

------------------------------------------------------------------------

## ✨ Features

-   ➕ Increment Counter
-   ➖ Decrement Counter
-   🔄 Reset Counter
-   🌐 Global State Management using Redux
-   🎨 Modern UI with Tailwind CSS

------------------------------------------------------------------------

## 🛠️ Tech Stack

-   ⚛️ React (Functional Components + Hooks)
-   🧠 Redux
-   🎨 Tailwind CSS

------------------------------------------------------------------------

## ⚙️ How to Run

``` bash
# Install dependencies
npm install

# Run the app
npm run dev
```

------------------------------------------------------------------------

## 🧠 Redux Flow (Important)

    UI → Dispatch Action → Reducer → Store Update → UI Re-render
