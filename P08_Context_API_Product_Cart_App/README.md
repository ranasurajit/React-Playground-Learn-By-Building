# 🛒 ProductSense - React Cart Application

## 🚀 Overview

ProductSense is a modern e-commerce UI built using **React + Tailwind
CSS**.\
It features product listing, cart management, and a clean responsive
layout.

------------------------------------------------------------------------

## ✨ Features

-   📦 Product Listing (API आधारित)
-   🛒 Add to Cart functionality
-   ➕ Increase / ➖ Decrease quantity
-   ❌ Remove items from cart
-   💰 Dynamic total price calculation
-   🎨 Clean UI with Tailwind CSS
-   📱 Responsive layout

------------------------------------------------------------------------

## 🧠 Tech Stack

-   React (Hooks)
-   Context API (State Management)
-   Tailwind CSS

## ⚙️ Setup Instructions

### 1. Clone the repository

``` bash
git clone <your-repo-url>
cd project-folder
```

### 2. Install dependencies

``` bash
npm install
```

### 3. Run the app

``` bash
npm run dev
```

------------------------------------------------------------------------

## 🎯 Key Concepts Used

### Context API

Global cart state is managed using React Context.

### State Management

-   Add / Remove / Delete items
-   Quantity handling

### Tailwind CSS

Used for rapid UI development and responsive design.
