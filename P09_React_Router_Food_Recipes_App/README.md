# 🍳 RecipeVerse

A modern React application to explore delicious recipes with dynamic routing and API integration.

---

## 🚀 Features

- 🔍 Browse recipes from API
- 📄 View detailed recipe information
- 🔗 Dynamic routing using React Router
- ♻️ Reusable components (RecipeCard, Navbar)
- 🎨 Clean UI built with Tailwind CSS

---

## 🛠️ Tech Stack

- ⚛️ React (Hooks)
- 🌐 React Router
- 📡 Axios
- 🎨 Tailwind CSS

---

## 📦 Installation & Setup

```bash
git clone https://github.com/ranasurajit/React-Playground-Learn-By-Building.git
cd React-Playground-Learn-By-Building
npm install
npm run dev
```
